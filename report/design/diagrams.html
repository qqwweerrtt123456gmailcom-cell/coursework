Архітектура LocalDo

Вкладка браузера
app.js — інтерфейс, події
model.js — валідація, LWW-злиття
sync.js — BroadcastChannel, експорт / імпорт
db.js — обгортка IndexedDB
IndexedDB «localdo»: сховища tasks і meta
Cache Storage «localdo-v1»: HTML, CSS, JS, іконки
sw.js — Service Worker (stale-while-revalidate)
Інші вкладки ⇄ BroadcastChannel
Інший пристрій ⇄ JSON-файл localdo/v1
GitHub Pages — лише роздає статичні файли

Злиття даних двох пристроїв (Last-Writer-Wins)

Пристрій A
#1 «Записка» · t=100
#2 «Презентація» · t=300
#3 «Звіт» · t=150
+
Пристрій B
#1 «Записка (B)» · t=200
#2 видалено · t=250
#4 «Купити хліб» · t=180
=
Результат (однаковий на A і B)
#1 «Записка (B)» — новіша
#2 «Презентація» — 300 > 250
#3 «Звіт» — лише на A
#4 «Купити хліб» — лише на B
